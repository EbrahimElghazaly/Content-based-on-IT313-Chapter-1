## 📖 About The Project (عن المشروع)

**ELGHAZALY WEB** is a modern, production-ready educational web app built to help students master the fundamentals of Information and Computer Network Security. It transforms static PDF content into an engaging, interactive learning experience.

**منصة "الغزالي ويب"** هي تطبيق ويب تعليمي احترافي، مصمم لمساعدة الطلاب على إتقان أساسيات أمن المعلومات والشبكات الحاسوبية. الموقع بيحول محتوى الـ PDF الثابت لتجربة تعليمية تفاعلية ممتعة.

---

## ✨ Key Features (أهم المميزات)

- 🌐 **Full Bilingual Support (AR/EN):** Instant language switching with seamless RTL (Right-to-Left) and LTR layout adjustments.
- 🌙 **Dark / Light Mode:** A beautiful, eye-friendly dark theme toggle saved to `localStorage`.
- 📱 **100% Responsive Design:** Perfectly optimized for mobiles, tablets, and desktop screens.
- 📚 **Comprehensive Summary:** 27 beautifully organized accordion sections covering the entire chapter.
- 🔍 **Live Search:** Search through the summary content in real-time.
- 💼 **20 Interactive Case Studies:** Scenario-based questions with instant feedback, explanations, and a final score card.
- 🎯 **15-Question Interactive Quiz:** Includes "Practice Mode" and "Exam Mode" with randomized questions.
- 🏆 **Detailed Results:** Progress rings, performance badges, and a full review of all answered/unanswered questions.
- 💾 **State Persistence:** Saves language, theme, and quiz progress in `localStorage`.

---

## 🛠️ Tech Stack (التقنيات المستخدمة)

This project is built using **Pure Vanilla Web Technologies** (No external frameworks or libraries):

- **HTML5** — Semantic markup & accessibility.
- **CSS3** — Custom properties (variables), Flexbox, CSS Grid, modern animations, and logical properties for RTL support.
- **JavaScript (ES6+)** — DOM manipulation, state management, bilingual logic, and interactive engines.
- **Google Fonts** — *Inter* (English) & *Cairo* (Arabic).
